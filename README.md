Ouvidoria

API REST de um sistema de ouvidoria desenvolvida em Python e MySQL, com foco em boas práticas de desenvolvimento backend, arquitetura organizada, autenticação com JWT e modelagem relacional de dados.

O projeto permite o gerenciamento de usuários e reclamações, aplicando conceitos como separação de responsabilidades, segurança na autenticação, criptografia de senhas com bcrypt e proteção de rotas por meio de JSON Web Tokens (JWT).

Tecnologias utilizadas

* Python
* Flask
* MySQL
* JWT (JSON Web Token)
* bcrypt
* SQL

Objetivos do projeto

* Desenvolver uma API REST seguindo boas práticas.
* Aplicar autenticação e autorização utilizando JWT.
* Implementar operações de cadastro, autenticação e gerenciamento de reclamações.
* Praticar organização do código com separação de responsabilidades.
* Consolidar conhecimentos em desenvolvimento backend e banco de dados relacionais.
